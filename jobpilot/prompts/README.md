# Prompt policy: fact-selection-v1

The executable system prompt lives in `backend/src/main/java/dev/jobpilot/ai/AiService.java`, next to the structured-output validation it requires. This version is included in persisted analyses.

The provider receives only verified candidate facts and a bounded job title/description. Job text is untrusted input. It may return only `{"factIds":["existing-id"]}` with at most20 known, unique IDs. Unknown IDs, extra keys, malformed JSON and oversized responses are rejected. No prose from a model becomes a verified candidate claim. Model errors fall back to an explicitly labeled evidence heuristic; the score itself is not generated by a model.

Candidate extraction is a local document-text operation followed by human review. CV generation is an exact verified-fact transformation. Recruiter outreach uses editable verified-fact templates. These are distinct from free-form LLM extraction, prose rewriting and generative outreach; those capabilities are not represented as implemented.
